# Knowledge Base

## Purpose

The `knowledge` directory contains AI-generated documentation that describes the application, its architecture, and other technical information needed to understand, maintain, and enhance the project.

The knowledge base serves as a long-lived technical reference for both AI agents and software developers. It should accurately reflect the current implementation of the application.

---

# Typical Contents

The knowledge base may include documentation such as:

- Project overview
- System architecture
- API documentation
- Database design
- Configuration
- Authentication
- Security implementation
- Deployment
- Frontend architecture
- Routes and pages
- Background jobs and automation
- Observability and logging
- Integrations
- Development tools
- Support information
- Changelog

Additional documents may be added as the project evolves.

---

# AI Agent Governance

The `knowledge/governance` directory contains the permanent engineering, architectural, security, and development standards that govern implementation decisions.

Unlike the rest of the knowledge base, governance documents define standards rather than project-specific implementation details.

AI agents should review the applicable governance documents before implementing changes.

---

# Maintenance

Documentation within this directory should:

- Reflect the current implementation of the application.
- Be updated whenever significant architectural or functional changes are introduced.
- Remain concise, accurate, and organized.
- Avoid duplicating information across documents whenever practical.
- Distinguish project-specific documentation from permanent governance standards.
