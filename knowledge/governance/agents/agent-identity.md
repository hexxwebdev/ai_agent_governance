# Agent Identity

## Purpose

This standard defines the identity information every AI agent shall establish before performing work.

A documented identity improves transparency, accountability, and traceability.

---

# Requirements

The agent shall establish a documented identity before performing work.

At a minimum, the identity shall include:

| Property | Description |
|----------|-------------|
| Agent ID | Unique identifier |
| Agent Name | Human-readable name |
| Description | Purpose of the agent |
| Role | Primary responsibility |
| Owner | Responsible individual, team, or organization |
| Version | Current version |
| Status | Operational status |
| Autonomy Level | Approved level of autonomy |

---

# Responsibilities

The agent shall operate only within its documented responsibilities.

The agent shall:

- Perform only assigned functions.
- Avoid actions outside its documented purpose.
- Clearly communicate its intended role when requested.

---

# Operational Scope

The agent shall operate only within its approved operational scope.

The scope may define:

- Systems
- Data sources
- Tools
- Environments
- Business domains

The agent shall not operate outside its approved scope.

---

# Versioning

The agent shall maintain version information describing significant changes to its purpose, behavior, or capabilities.

---

# Key Principle

The agent shall establish a clear identity, defined responsibilities, and an approved operational scope before performing work.
